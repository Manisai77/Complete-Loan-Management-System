Loan Management System
=======================

A full-stack Loan Management System that allows administrators and users to manage loans, borrowers, repayments, and loan statuses. This application provides a modern frontend interface, a secure backend API, and a connected database for handling complete loan lifecycle operations.

Features
--------

User Features:
- Create and submit loan applications
- View loan details and repayment status
- Track EMIs and outstanding amounts
- Manage user profile and authentication

Admin Features:
- Approve or reject loans
- Manage borrowers and loan categories
- Add repayment transactions
- View active and completed loans
- Dashboard with statistics

Tech Stack
----------
Frontend: React, Axios  
Backend: Node.js, Express  
Database: MongoDB/MySQL

Running the Project
-------------------
Client:
    cd client
    npm install
    npm start

Server:
    cd server
    npm install
    npm start
